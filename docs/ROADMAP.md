# Roadmap

## Phase 2

- Daily, weekly, monthly, and total writing goals.
- Progress bars and target dates.
- Chapter goals.
- Heatmap-style activity from snapshot history.
- Scheduled sync after manual sync behavior is proven.

## Phase 3

- Public Notion OAuth installation.
- Multi-user accounts and workspaces.
- Secure encrypted token storage.
- Disconnect and deletion flows.
- Hosted deployment and onboarding.

## Phase 4

- Optional Notion write-back to a selected dashboard or database.
- Manuscript total, period progress, goal percentage, and last sync fields.

## Possible later work

- Embeddable writing widgets.
- Multiple manuscript comparison.
- CSV and JSON analytics export.

Wordsmith will not add AI prose generation, grammar rewriting, or editing suggestions as part of this product direction.
